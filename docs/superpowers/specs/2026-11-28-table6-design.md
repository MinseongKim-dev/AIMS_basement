# 설계: 논문 Table 6 (파인튜닝 Phi3.5V-Med) 재현

작성 2026-11-28. 상태: 승인(2026-11-28, 대화에서 제시한 설계).

## 목적
논문 부록 D Table 6의 파인튜닝 두 행(`Label prob.`, `Entropy`)을 test의 closed 문항에서 계산한다. Zero-Shot과 `Is True prob.`은 만들지 않는다.

## 방법 비교
| 방법 | 선택 |
|---|---|
| A. 인용 문헌 [44](Tian 외 2023, arXiv 2305.14975)의 지표 정의를 따른다. AUC = 선택 정확도–커버리지 | **선택**: 같은 방법 · 지표 이름, 저장된 예측으로 0.967 / 0.941 (논문 0.958 / 0.949) |
| B. AUC를 ROC-AUC로 읽는다 (이전) | 약 0.80으로 논문과 맞지 않음. 비교용 열로만 남긴다 |

논문이 [44]의 정의를 그대로 썼다는 명시는 없다. 수치가 맞는 것은 정황이다.

## 실행 전에 고정한 정의
- 문항: test의 `answer_type == CLOSED`. 표는 closed 전체와 그중 yes/no 정답 문항을 **둘 다** 낸다(부록 표 설명은 "yes/no" QA, 표 머리글은 Closed).
- 정답 판정: 원본(Phi) 채점 `score_phi == 1`.
- greedy 답: `Entropy` 행. 순위는 식 4(특수 토큰 제외, 낮을수록 확신), 신뢰도는 답 토큰 확률의 기하평균 `exp(mean log p)` (`A token prob (greedy)`의 해석, 식 3의 길이 정규화).
- 샘플: temperature 1, top-p 1로 10번. `Label prob.` 행의 답은 가장 많은 답(정규화해 묶고, 동수면 먼저 나온 것), 신뢰도는 그 비율, 순위도 신뢰도.
- AUC: 신뢰도가 높은 순으로 k = 1..n개를 포함할 때의 정확도 평균. 동점은 순서에 대한 기댓값.
- ECE: [0, 1]을 폭이 같은 10구간, `Σ (n_b/n)·|정확도 − 평균 신뢰도|`. **구간 수는 논문과 [44]에 없어 우리가 정함.**
- temperature: `p' = p^β / (p^β + (1−p)^β)`, β는 NLL 최소(ln β ∈ [−5, 5]). 문항을 seed 0으로 섞어 5-fold, 한 fold에서 맞추고 나머지 4 fold에서 계산해 평균([44] 부록 B, 요약 기준). BS = 신뢰도와 정오의 평균 제곱 오차.
- 빈 greedy 답(엔트로피 없음)은 두 행에서 함께 빼고 개수를 적는다.
- 무작위 순서의 AUC 기댓값은 정확도와 같으므로 정확도를 함께 적는다.

## 원칙
위 정의는 논문 수치에 맞추려고 바꾸지 않는다. 맞지 않으면 그대로 보고한다. 이 계산으로 게이팅이나 팀 명세는 바꾸지 않는다.
